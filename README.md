Student Management System

A basic Student Management System developed using C++ to manage student records efficiently.

Features

- Add student records
- Display all student records
- Search students by enrollment number
- Update student details
- Delete student records
- Store name, enrollment number, branch, semester, and marks

Technologies Used

- C++
- Vectors
- Structures
- Functions
- Loops and Conditional Statements

How to Run

1. Clone or download this repository.
2. Open the project in VS Code or any C++ IDE.
3. Compile the program.
4. Run the executable.
5. Select an option from the menu to manage student records.

Purpose

This project is created to practice basic C++ programming concepts and CRUD operations.
